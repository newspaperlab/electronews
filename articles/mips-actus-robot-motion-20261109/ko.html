MIPS Actus, 로봇 관절 안에 제어·추론·통신을 모은다

AI의 판단을 실제 모터 움직임으로 옮기는 단계에 실시간 처리와 시간 민감형 네트워크를 결합한다.

Newspaper Lab 편집 · 게시 2026-11-12
원문 발표 2026-11-09

MIPS가 11월 9일자 공식 발표에서 로봇 관절용 Actus 참조 플랫폼의 발전 내용을 공개했다. 두 개의 Atlas M8500 실시간 RISC-V 처리기와 모터 제어 가속, 엣지 추론 및 통신을 결합하는 구성이다. 완성된 휴머노이드 로봇을 판매한다는 발표가 아니라, 로봇을 만드는 기업이 정밀한 움직임을 구현할 때 사용할 제어 기반을 제시한 것이다. 전시 일정은 11월 10~13일 electronica다.

MIPS는 처리기 기술과 관련 플랫폼을 제공하며 이번 발표에서는 ‘MIPS, by GF’라는 이름을 사용한다. GF는 반도체 제조사 글로벌파운드리다. Actus는 GF의 FDX FD-SOI 기술을 바탕으로 작은 로봇 관절에서 공간과 전력, 발열을 함께 다루려는 설계다. 로봇 팔에서 손끝에 가까워질수록 모터와 센서, 회로를 넣을 공간이 제한된다. 중앙에서 똑똑한 결정을 내려도 각 관절이 제때 반응하지 못하면 원하는 움직임으로 이어지지 않는다.

실시간 제어의 핵심은 단순히 평균 속도가 빠르다는 데 있지 않다. 센서 값을 읽고 모터에 명령을 보내는 작업을 필요한 시간 안에 반복하는 것이 중요하다. RISC-V는 처리기가 이해하는 명령 체계의 공개 표준으로, 모든 RISC-V 칩의 성능과 주변 장치가 같다는 뜻은 아니다. MIPS는 하드웨어 멀티스레딩으로 인터럽트 처리 중 작업 전환 부담을 줄인다고 설명한다. 실제 효과는 실행 코드와 제어 주기에 따라 확인해야 한다.

회사는 모터 제어 알고리즘에 쓰이는 삼각함수 전용 가속이 표준 삼각함수 라이브러리보다 16배 넘는 성능을 제공한다고 밝혔다. 이는 해당 연산의 비교이며 로봇 팔 전체가 16배 빨라진다는 의미가 아니다. PWM은 모터에 전력을 주는 펄스의 폭을 제어하는 방식으로, 자료는 100피코초급 고해상도 PWM도 제시한다. 이 역시 제어 신호의 세밀함에 관한 수치이지 로봇 손끝의 위치 오차를 직접 나타내는 값은 아니다.

통신도 움직임의 일부다

Actus는 기가비트 이더넷과 3포트 TSN, CAN-FD 등을 통합한다고 설명한다. TSN은 시간에 민감한 데이터가 예측 가능한 방식으로 전달되도록 돕는 네트워크 기술이다. 여러 관절이 위치와 토크 정보를 주고받을 때 지연의 흔들림을 줄이는 것이 중요하다. 통신 규격을 지원한다는 사실만으로 로봇 전체의 동기화가 완료되는 것은 아니며, 네트워크 구성과 다른 제어기의 조건까지 맞아야 한다.

엣지 추론은 데이터를 외부 서버로 모두 보내지 않고 관절 가까이에서 처리하려는 기능이다. 회사는 센서 융합과 예지 정비 모델을 같은 칩에서 실행하는 구상을 제시했다. 기능 안전 지원과 양자내성 암호를 갖춘 보안 모듈도 포함한다. 그러나 ‘지원’이라는 말은 완성 로봇이 모든 안전 인증을 받았다는 뜻이 아니다. 안전한 동작은 기계 구조, 제어 소프트웨어와 전체 시스템 검증을 함께 요구한다.

개발자는 실제 칩을 받기 전 가상 플랫폼에서 소프트웨어를 시작하고, 이후 Actus-1 평가 보드와 SDK로 옮기는 경로를 안내받는다. 구체적인 양산 공급일과 가격은 발표에 없다. 편집부는 AI 성능만 강조하던 설명에서 관절의 제어 주기와 네트워크까지 함께 설계하는 방향에 의미가 있다고 본다. 다만 독립적인 로봇 시험 결과가 제시된 것은 아니므로 전력 절감률이나 실제 작업 정확도를 확정 성능으로 덧붙이지 않았다.
