8GB PC를 덜 답답하게, Windows가 메모리를 쓰는 순서를 바꾼다

마이크로소프트가 반응성과 메모리 개선을 소개했다. 업데이트 효과와 메모리 증설의 역할을 함께 살펴봤다.

Newspaper Lab 편집 · 게시 2026-11-06
원문 발표 2026-11-03

브라우저 탭 몇 개와 문서를 열었을 뿐인데 시작 메뉴까지 늦게 반응하면, 사용자는 컴퓨터 전체가 느려졌다고 느낀다. 마이크로소프트는 11월 3일 8GB 메모리 Windows 11 PC에서 이런 일상 동작을 개선하는 작업을 소개했다. 핵심은 메모리를 더 효율적으로 쓰고, 지금 사용자가 요청한 작업에 우선순위를 주는 것이다.

기다리는 작업부터 줄이기

회사는 사용자가 활동하는 동안 검색 색인 같은 백그라운드 작업의 부담을 낮추고, 앱 실행 경로를 줄이는 접근을 설명했다. 체감 속도는 CPU의 최고 성능만으로 정해지지 않는다. 클릭한 작업이 자원을 얻기까지 얼마나 기다리는지도 영향을 준다.

공식 자료에는 특정 복합 작업을 최대 40% 빠르게 끝냈다는 내부 시험 결과가 있다. 같은 PC에서 여러 앱과 탭을 연 조건의 비교이므로, 모든 8GB PC가 모든 작업에서 40% 빨라진다는 의미로 확대해서는 안 된다. 자신의 기기에서는 저장장치와 프로세서, 상주 프로그램의 영향을 함께 받는다.

소프트웨어 개선이 RAM을 늘려주지는 않는다

8GB라는 물리적 용량 자체는 업데이트로 바뀌지 않는다. 동시에 쓰는 앱이 많거나 큰 영상과 3D 데이터를 다루면 여전히 더 큰 메모리가 유리할 수 있다. 반응성을 개선하는 일과 대규모 작업을 담을 공간을 늘리는 일은 서로 보완 관계다.

회사가 안내한 적용 기준은 Windows 11 26H2 빌드 26300.9818 이상이다. Edge와 Microsoft 365, Teams 같은 앱의 업데이트도 일부 개선과 연결된다. PC마다 제공 시점과 지원 상태가 다를 수 있으므로 Windows Update에서 자신의 기기에 제시되는 내용을 확인해야 한다.

오래된 PC를 쓰는 사람에게 이번 소식은 무조건 새 제품을 사라는 얘기보다 현실적인 확인 순서를 준다. 업데이트와 앱 상태를 먼저 살피고, 평소 작업 중 메모리 사용량을 확인한 뒤, 업그레이드 가능한 모델인지 알아보는 것이다. 불편의 원인을 분리해야 지출도 정확해진다.
