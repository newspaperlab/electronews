32GB 그래픽 메모리는 어디에 쓰일까, Arc Pro B70의 다른 기준

ASUS가 로컬 AI용 UGen 카드를 공개했다. 게임용 카드와 다른 메모리·소프트웨어 조건을 살펴봤다.

Newspaper Lab 편집 · 게시 2026-11-06
원문 발표 2026-10-27

그래픽카드의 메모리 용량을 볼 때 게임의 고해상도 텍스처부터 떠올리기 쉽다. 로컬 AI에서는 같은 메모리에 모델의 가중치와 실행 중 데이터가 함께 들어간다. ASUS가 10월 27일 공개 페이지에서 소개한 UGen Intel Arc Pro B70 32GB는 이 수요를 겨냥한다. 본문 발표 날짜는 10월 23일로 표기돼 있다.

모델을 담는 공간과 계산하는 속도

공개된 메모리는 32GB ECC GDDR6다. ECC는 메모리 오류를 감지하고 정정하는 기능을 가리킨다. 용량은 실행할 데이터를 담을 수 있는지와 연결되지만, 생성 속도는 연산 성능과 메모리 대역폭, 프로그램 구현에도 영향을 받는다. 32GB라는 숫자만으로 다른 카드보다 항상 빠르다고 말할 수는 없다.

모델의 매개변수 수 역시 필요한 메모리를 하나로 정해주지 않는다. 데이터 표현 정밀도와 양자화 방식, 입력 길이, 동시에 처리하는 요청에 따라 사용량이 달라진다. 같은 모델 이름을 봤더라도 실행 설정이 다르면 결과를 그대로 비교하기 어렵다.

여러 장을 꽂으면 하나처럼 합쳐지는가

회사는 다중 카드 구성을 통한 확장을 제시한다. 그러나 카드별 용량을 더한 값과 프로그램이 자동으로 하나의 메모리처럼 쓰는 것은 다른 문제다. 소프트웨어가 작업과 데이터를 나누어 처리할 수 있어야 하고, 카드 사이의 데이터 이동도 고려해야 한다.

공식 자료는 지원 가능한 여러 실행 도구를 열거한다. 실제 구매 전에는 사용하려는 프레임워크의 버전과 해당 GPU 지원 상태를 확인하는 것이 먼저다. 예제 하나가 실행된다는 사실과 평소 쓰는 모든 작업이 안정적으로 돌아간다는 것은 같은 수준의 검증이 아니다.

이 카드의 의미는 모든 PC에 AI용 GPU가 필요하다는 데 있지 않다. 자기 컴퓨터 안에서 큰 데이터를 처리하려는 사용자가 게임 프레임률 외의 기준으로 부품을 비교한다는 변화에 있다. 필요한 모델과 소프트웨어를 정한 뒤 메모리·전력·실행 성능을 함께 계산해야 용량의 가치를 알 수 있다.
